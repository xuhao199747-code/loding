# AI 批量生成工作台复刻版设计规格

## 1. 目标

在当前空工作区中实现一个桌面端 AI 批量生成工作台，完整覆盖参考站点的核心功能，并将视觉和交互升级为更精致的专业创作工具。产品默认支持离线演示，也支持在设置中切换到真实 APImart API。

## 2. 范围与约束

- 仅优化桌面端，目标宽度为 1280–1920px。
- 不实现账号系统、云端数据库或独立上传服务。
- 配置、任务和自定义模型使用浏览器本地存储。
- 离线模式无需 API Key，可创建模拟任务并展示模拟结果。
- 真实 API 模式沿用同一套任务状态和结果展示组件。
- 保留参考站点的信息架构，但不复制其样式细节。

## 3. 视觉方向

- 深蓝黑背景，使用蓝紫渐变作为主强调色。
- 顶部导航、配置面板、任务卡片采用轻玻璃质感和细边框。
- 通过字号、灰度和间距建立清晰的信息层级。
- 状态颜色：蓝色表示运行中，绿色表示成功，黄色表示提示，红色表示失败。
- 任务结果采用更大的缩略图与更少的冗余信息，降低扫视成本。

## 4. 页面结构

### 顶栏

- 品牌名和产品副标题。
- 生图 / 生视频模式切换。
- 当前模式的任务统计。
- 离线 / API 连接状态。
- 余额提示与 API 设置入口。

### 左侧生成配置面板

- 多行提示词输入，每行创建一个独立任务。
- 可展开的负向提示词。
- 参考图添加：本地文件、拖拽、粘贴截图、URL。
- 参数选择：比例、清晰度、生视频时长、音频开关、生成数量。
- 按厂商分组的模型选择，支持多选、禁用原因和模型能力标签。
- 底部显示预计任务数和预计费用提示。
- 主按钮创建任务。

### 右侧任务工作区

- 筛选：全部、进行中、成功、失败。
- 操作：重试失败、下载全部成功、清空任务。
- 任务卡片网格：缩略图、模型、状态、提示词、参数、耗时和操作按钮。
- 空状态提供示例提示词和开始生成入口。

### 弹层与抽屉

- API 设置弹层：Base URL、API Key、测试连接、自动下载、自定义模型。
- 结果详情弹层：媒体预览、提示词、模型、参数、耗时、费用、复制、打开链接、下载。
- 清空任务确认弹层。
- Toast 用于保存、校验、生成、失败和下载反馈。

## 5. 数据与状态

核心状态分为四层：

1. `mode`：当前是 image 还是 video。
2. `draft`：当前提示词、参考图和生成参数。
3. `tasks`：任务队列，包含 queued、running、success、error 四种状态。
4. `settings`：API 配置、离线模式、自动下载和自定义模型。

离线模式通过模拟器创建任务：任务先进入排队，再按时间推进到成功或失败；成功任务使用内置渐变图卡或可访问的示例媒体地址。真实 API 模式通过统一适配器提交、轮询和归一化结果，避免 UI 直接依赖 APImart 返回结构。

## 6. 交互规则

- 提示词按非空行拆分；Ctrl/Cmd + Enter 开始生成。
- 未选择模型时禁止生成并提示用户。
- 参考图不满足模型能力时，模型卡显示禁用原因。
- 生图和生视频切换时分别保存各自的参数和模型选择。
- 失败任务可单独重试，也可批量重试。
- 任务详情中的“作为参考图”会把结果加入配置面板。
- 配置、任务和自定义模型刷新页面后保持。
- 所有危险操作需要确认。

## 7. 组件边界

- `AppShell`：整体布局和顶栏。
- `PromptPanel`：提示词、参考图、参数和生成操作。
- `ModelPicker`：厂商分组、能力标签和多选逻辑。
- `TaskWorkspace`：筛选、批量操作和任务网格。
- `TaskCard`：单任务状态和快捷操作。
- `TaskDetailDialog`：媒体预览和任务详情。
- `SettingsDialog`：API 配置与自定义模型。
- `task-engine`：离线模拟、真实 API 适配、轮询和状态归一化。
- `storage`：浏览器本地存储读写。

## 8. 验证标准

- 桌面端首屏在 1280px 宽度下不出现横向滚动。
- 生图、生视频模式均可创建多提示词任务。
- 离线模式无需 API Key 能完成创建、进度、成功、失败、重试和清空流程。
- API 设置、自定义模型、任务和界面参数刷新后仍保留。
- 结果预览、复制提示词、下载和“作为参考图”均可操作。
- 构建命令成功通过，交互关键路径完成浏览器检查。
