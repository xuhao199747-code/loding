# 旅游行业 KOS 全流程整合 Demo 改造设计

## 目标

将现有寿险智能展业 KOS 单文件 demo 深度改造成旅行社/旅游平台的一体化增长工作台，保留现有单文件交付和三视图切换能力，同时让导航、经营指标、线索、顾问对话、内容与调度全部围绕旅游业务展开。

## 范围

- 外壳品牌与导航：KOS → 旅游增长工作台；战情、监控、对话改为经营总览、线索监控、旅行顾问。
- 经营总览：展示 GMV、订单量、支付转化率、获客成本、热门目的地、渠道表现和待办机会。
- 线索监控：展示来自微信、抖音、小红书、携程等渠道的游客咨询，包含目的地、预算、出行日期、人数和意向等级。
- 旅行顾问：将对话流程改成需求识别、线路推荐、报价、异议处理、下单和出行服务，并保留跨视图定位。
- 内容中心与跟进调度：启用现有未开放入口，展示攻略/短视频内容生产和报价、支付、出发前、复购召回等任务。
- 示例数据：统一替换为三亚亲子、川西稻城、新疆包车、关西自由行等旅游场景。

## 交互与兼容

- 保留现有页面布局、视觉语言、iframe/srcdoc 单文件架构和父子消息桥。
- 导航入口全部可点击；原有“演示版未开放”入口改为对应旅游模块的可用视图。
- 跨视图跳转从“客户对话”改为“游客咨询/线索”，保持通过 ID 定位到对应游客。
- 不引入外部网络依赖，确保通过 `file://` 直接打开仍可运行。

## 验证标准

- HTML 可被浏览器直接打开，首屏正常渲染。
- 页面中不再出现寿险、保险、展业等旧业务文案。
- 经营总览、线索监控、旅行顾问、内容中心、跟进调度五个模块均有旅游行业示例内容。
- 点击线索卡片可跳转到旅行顾问并定位对应游客。
- 文件仍为单个 HTML，且脚本无语法错误。
