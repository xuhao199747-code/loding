# KOS 旅游获客控制台功能对齐设计

## 目标

在不继续使用旧版单文件 HTML 的前提下，用现有 React + TypeScript + shadcn/ui 架构补齐旧版 KOS 旅游获客控制台的主要页面、交互和状态变化。视觉继续使用当前 shadcn 风格，功能与交互按旧版行为对齐。

## 功能范围

| 旧版功能面 | 新版模块 | 必须迁移的行为 |
| --- | --- | --- |
| 经营总览 | `overview` | 指标卡、经营漏斗、机会卡、快捷进入游客监控、今日报告、诊断结果和行动建议 |
| 游客监控中心 | `monitor` | 全部/小红书/抖音/企业微信渠道切换、五阶段看板、阶段人数、游客卡片、展开详情、空状态 |
| 破冰 | `monitor` + `dialog` | 留资、加企微、接管会话、标记高意向、打开游客详情、推进到下一阶段 |
| 意向热聊 | `monitor` + `dialog` | AI 识别结果、需求确认题数、确认意向、自动跟进会话列表、会话状态更新 |
| 方案报价/预订支付/出行服务/长期经营 | `monitor` + `dialog` | 阶段卡片、下一步动作、报价确认、支付提醒、出发前提醒、复购召回状态 |
| 旅行顾问工作台 | `advisor` | 会话列表切换、消息列表、发送消息、AI 副驾建议、一键采用话术、游客摘要 |
| 旅游内容中心 | `content` | 新建内容、内容生产队列、编辑状态、发布状态、渠道表现、目的地表现 |
| 跟进调度中心 | `schedule` | 待跟进统计、刷新任务、联系、打开对话、出行服务、复购召回、服务节奏指标 |
| 今日报告/AI 诊断 | `report` | 经营健康度、漏斗转化、高风险占比、今日建议、查看报告和关闭报告 |

## 交互状态

### 渠道

所有需要渠道筛选的区域使用统一渠道值：`all`、`xhs`、`dy`、`wx`。切换渠道只影响当前看板或列表，不改变全局数据。无数据时显示对应渠道的空状态，并保留切换入口。

### 游客流程

游客状态使用五个阶段：`breakthrough`、`intent`、`proposal`、`payment`、`travel`。每张游客卡都能打开详情。详情中提供当前阶段动作；动作执行后更新游客状态、记录一条时间线事件，并给出可见的成功反馈。不能执行的动作显示禁用原因，不使用无行为按钮。

### 对话

会话列表切换当前游客；发送消息后消息立即进入列表并清空输入框；采用 AI 话术后写入消息列表；接管、留资、加企微、确认意向均更新游客标签和会话状态。所有状态变化只保存在本地演示状态中，刷新页面恢复演示初始数据。

### 内容与调度

内容支持草稿、审核中、已发布三种状态；新建内容进入草稿列表，编辑和发布按钮会更新状态。调度任务支持待处理、已联系、已完成三种状态；联系、打开对话、出行服务、复购召回分别更新任务状态并显示反馈。

### 报告

今日报告从总览右上角打开，使用 shadcn `Dialog`。报告包含健康度、漏斗转化、高风险占比、建议动作四个区域；关闭后回到原页面，不丢失当前渠道和游客选择。

## 组件边界

- `App.tsx` 只维护当前页面、选中游客、报告开关和跨模块事件，不承载业务计算。
- `data/tourism.ts` 提供初始演示数据和类型；新增数据类型必须放在这里或同目录的独立数据文件中。
- `lib/filtering.ts` 放渠道过滤、阶段过滤和状态派生等无副作用函数。
- 每个页面模块只负责布局和页面级事件；卡片、列表项、弹窗和操作栏拆成可测试的子组件。
- 所有按钮使用本地 shadcn `Button`，所有标签使用 `Badge`，所有弹层使用 `Dialog`，所有切换使用 `Tabs`；不新建平行的按钮、卡片或弹窗实现。

## 验收标准

1. 左侧导航可以进入总览、游客监控、顾问、内容、调度五个页面。
2. 监控页面的四个渠道 TAB 在所有相关列表中可用，切换结果正确，空状态正确。
3. 五阶段的游客卡片都可以打开详情；详情动作会产生可见状态变化和时间线记录。
4. 顾问工作台可以切换会话、发送消息和采用 AI 话术。
5. 内容中心可以新建、编辑和发布内容，调度中心可以刷新和完成任务动作。
6. 今日报告可以从总览打开和关闭，报告内容完整可见。
7. 页面在桌面宽度和窄屏宽度下无横向溢出，长中文文本不覆盖按钮。
8. 每个新增行为都有测试；`npm test -- --run` 和 `npm run build` 均通过。

## 不在本轮范围

- 不接真实后端、真实渠道 API、真实消息推送或持久化数据库。
- 不把旧版 HTML 的 base64 iframe 继续嵌入新项目。
- 不做旧版像素级视觉复制；只对齐信息架构、功能和交互反馈。
