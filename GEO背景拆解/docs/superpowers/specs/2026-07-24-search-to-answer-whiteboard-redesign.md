# Search Engine → Answer Engine 画板重设计

## 目标

覆盖重做飞书画板 `NUyKwFdseh68ZybXjdvc9lDMnaf`，修正 AI Search 链路中 RAG 与“检索召回”重复的问题，并提升画板的信息层级、可读性和视觉完成度。

## 信息结构

画板标题为“从 Search Engine 到 Answer Engine”，采用上下双泳道对比。

### Traditional Search（传统搜索）

分成离线索引与在线查询两个阶段：

1. 网页发现
2. 网页爬取
3. 页面解析
4. 索引构建
5. Query 理解
6. 召回
7. 排序
8. SERP 展示

目标卡片：索引覆盖、排名提升、点击增长。

### AI Search（人工智能搜索）

明确拆成两条子链路。

离线知识构建：

1. 内容采集
2. 清洗与 Chunking（文本切片）
3. Embedding（向量化）与实体关系抽取
4. Graph / Vector / KV（图、向量、键值存储）
5. 知识索引

在线 RAG 查询：

1. 用户提问
2. Query 理解与改写
3. Hybrid Retrieval（BM25 + Vector + Graph）
4. Context 构建
5. LLM 推理与生成
6. Answer + Citation（答案与引用）

目标卡片：被发现、被理解、被引用、被推荐。

## 视觉方案

- 暗色主题，使用深蓝黑背景，避免纯黑。
- 传统搜索泳道使用冷蓝色；AI Search 泳道使用青绿到紫色。
- 中文为主，关键技术名词保留英文，避免大段双语重复。
- 使用圆角卡片、阶段标签、方向箭头和少量高亮徽标建立层级。
- 离线与在线阶段用分区标题和视觉分隔线区分。
- 目标卡片放在每条泳道右侧，形成对照。
- 画布按内容收紧，消除原图下方大面积留白。
- 保持投屏和文档内嵌时可读，正文不使用过小字号。

## 实现与验收

- 使用 SVG 重绘并覆盖写入原画板。
- 本地渲染预览后检查文字溢出、节点重叠、箭头断裂和留白比例。
- 写入后重新导出飞书画板预览，与本地预览比对。
- 验收标准：RAG 不再作为“找资料”的单独重复节点；离线知识构建和在线检索生成边界明确；中文可读；暗色视觉统一；无明显空白、重叠和截断。

## 范围边界

- 本次只覆盖更新指定画板，不修改飞书文档其他内容。
- 画板表达的是项目材料中的概念链路，不宣称外部 AI Search 平台都使用完全相同的内部实现。
