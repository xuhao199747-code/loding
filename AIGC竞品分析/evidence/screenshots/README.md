# Screenshot Evidence

Screenshots are stored with these prefixes:

| Prefix | Product |
|---|---|
| AR-IMG | AlphaRank |
| AIDSO-IMG | AIDSO GEO |
| IMP-IMG | ImpetaAI |
| PRO-IMG | Profound |

Every screenshot must include:

- Screenshot ID.
- Product.
- Page/module.
- What it proves.
- Source URL.
- Capture date.

Screenshot files should be named like:

- `AR-IMG-001-geo-diagnosis.png`
- `AIDSO-IMG-001-home-entry.png`
- `IMP-IMG-001-positioning.png`
- `PRO-IMG-001-home-positioning.png`
