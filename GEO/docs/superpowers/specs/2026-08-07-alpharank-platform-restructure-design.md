# AlphaRank 新版平台功能重构规格

## 背景

当前 Demo 已经完成了一批新版 UI 页面，但功能边界出现混合：品牌能见度查询里放入了结果看板和监控资产，数据大盘、AI 引用、情感、提及率等结果页与配置页职责不清。后续改版以旧版 AlphaRank 平台作为功能主线，以飞书文档中的“品牌能见度智查”作为查询流程补充，不再凭截图零散添加功能。

## 目标

将 Demo 调整为一个统一的 GEO/AI 品牌监测平台：

- 保留新版 UI 视觉语言、侧边栏结构、组件规范和 Tailwind/shadcn 写法。
- 保留现有结果类模块：数据大盘、AI 对话记录、AI 引用来源、分平台 AI 引用统计、品牌情感倾向、品牌提及率。
- 新增并正式化配置类模块：提示词管理、打点管理。
- 将品牌能见度查询改为单一任务创建流程，不再承担结果页和资产管理职责。
- 所有行详情统一使用右侧抽屉，不再使用大块表格内展开或居中弹窗。

## 信息架构

### 营销Agent

入口：`/` 或 `/marketing-agent`

职责：

- 多 Agent 对话与任务分发。
- 包含 DataAgent、Strategy Agent、Writer Agent，以及 Multi-Agent。
- 使用 ai-elements 呈现假的 AI 思考、生成和结果卡片流程。
- 可以读取品牌监测结果，生成策略建议或内容建议。

不负责：

- 不直接管理提示词库。
- 不直接维护品牌打点数据。

### 品牌能见度查询

入口：`/geo-diagnosis`

职责：

- 创建一次品牌能见度查询或订阅追踪任务。
- 采用一步步流程：
  1. 品牌信息：品牌/产品名、别名、品类、官网。
  2. 用户搜索词：系统推荐或手动添加。
  3. AI 平台：选择豆包、Kimi、通义千问、DeepSeek、百度 AI、腾讯元宝等。
  4. 确认提交：确认搜索词数量、平台数量、采样方式和运行频率。
- 提交后进入品牌监测工作台查看结果。

不负责：

- 不展示完整数据大盘。
- 不展示历史诊断大表。
- 不承载提示词管理和打点管理的长期维护能力。

### 品牌监测工作台

这是结果类模块集合，不是单独页面标题。侧边栏展开时归组展示，折叠时保留现有图标。

保留模块：

- 数据大盘：整体 KPI、可见度、情感、竞品排名、回答记录。
- AI 对话记录：提示词、平台、对话结果、点击行打开 AI 问题抽屉。
- AI 引用来源：引用平台、引用排名、相关引用页面、顶级引用域、热门引用页面。
- 分平台 AI 引用统计：按平台查看品牌/竞品引用统计、气泡矩阵和排名。
- 品牌情感倾向：积极/消极情绪、情感趋势、情感模式、回复详情。
- 品牌提及率：品牌提及率排名、提及趋势、排名详情抽屉。

统一规则：

- 页面标题、二级标题、表格标题使用同一套字号和字重。
- 过滤器使用统一 shadcn Select/Input/Button 组合。
- 右上角无“重置/保存”按钮，除非页面本身是配置页。
- 表格 hover 行为统一；需要禁用 hover 的页面保持白底。
- 详情统一右侧 Sheet 抽屉，关闭按钮无边框。

### 提示词管理

入口：`/prompts`

职责：

- 管理系统推荐词、手动添加词、监控问题、Prompt 分组。
- 从品牌能见度查询流程中沉淀搜索词。
- 支持按品牌、品类、平台、状态筛选。
- 支持启用/停用监控问题。
- 支持从某个提示词进入相关 AI 对话记录或品牌提及结果。

核心页面内容：

- 顶部：标题“提示词管理”，说明文本。
- 筛选：品牌、品类、平台、状态、搜索。
- 表格：提示词、来源、所属品牌/品类、监控平台、状态、最近运行、操作。
- 抽屉：提示词详情，展示相关平台回答、品牌是否被提及、竞品出现情况。

### 打点管理

入口：`/checkpoints`

职责：

- 管理平台监测所需的基础对象。
- 包含品牌名、别名、品类、官网、竞品、平台、地区、标签。
- 为品牌能见度查询和监测结果页提供基础数据。

核心页面内容：

- 顶部：标题“打点管理”，说明文本。
- Tabs：品牌资料、竞品资料、品类/地区、AI 平台。
- 品牌资料：品牌名、别名、官网、描述、目标地区。
- 竞品资料：竞品名称、官网、品类、是否参与监测。
- 品类/地区：可维护常用标签。
- AI 平台：平台启用状态和展示顺序。

## 数据流

1. 打点管理维护品牌、竞品、品类、平台等基础资料。
2. 提示词管理生成和维护问题词/Prompt 池。
3. 品牌能见度查询读取打点数据和提示词，创建查询或订阅任务。
4. 品牌监测工作台消费查询结果并展示各类结果页。
5. 营销Agent读取结果，生成策略建议、内容建议或任务。

## 需要删除或收敛的现状

- 删除品牌能见度查询页中的“查询资产”长期管理模块。
- 删除品牌能见度查询页中的历史诊断结果大表，查询提交后的结果进入品牌监测工作台。
- 删除或隐藏泛化的早期页面入口：项目、竞品分析、内容机会、设置。若后续需要，可分别合并到打点管理、提示词管理或营销Agent。
- 保留当前侧边栏中用户确认的六个结果模块图标和入口。

## 组件规范

- 组件优先使用 shadcn/ui：Table、Tabs、Sheet、Select、Input、Button、Badge、Textarea。
- 对话和生成流程使用 ai-elements。
- 图标优先使用 lucide 或已有设计稿导出的图标。
- 色值使用 Tailwind token 或现有 CSS 变量，不直接散写任意颜色。
- 不改变已确认的新版视觉风格，只调整功能边界和页面内容。

## 验收标准

- 侧边栏信息架构清晰区分：营销Agent、品牌能见度查询、品牌监测工作台、提示词管理、打点管理。
- 品牌能见度查询呈现一步步流程，而不是结果页。
- 六个品牌监测结果页仍可访问，并使用统一标题、筛选、表格和抽屉规范。
- 提示词管理和打点管理成为正式模块，而不是临时塞在其他页面下方。
- 所有新增交互可以使用 mock 数据，不接后端。
- 构建通过，关键路由测试通过。
