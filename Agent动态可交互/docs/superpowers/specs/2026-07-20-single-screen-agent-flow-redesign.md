# Agent 流程单屏重设计

## 目标

把当前多层导航式演示重做为固定全景流程演示。浏览器缩放 100%、视口不小于 1366×768 时，标题、完整架构、全部主要节点与连线、当前步骤说明、上一步与下一步控制必须同时可见，页面不得产生横向或纵向滚动。

## 明确移除

- 小地图及其进入、折叠、返回现场逻辑。
- 镜头缩放、模块聚焦、节点聚焦和自动跟随。
- 覆盖主画布的悬浮检查器。
- 自动播放与速度选择。
- 为历史浏览服务的复杂视图状态；底层执行历史仍可保留，但不进入本次主界面。

## 页面结构

页面固定为 100vw × 100vh，并使用三行布局：

1. 顶栏：双语标题、场景选择、当前进度，控制在约 64px。
2. 主体：左侧完整流程图，右侧固定步骤说明栏。主体自动占满剩余高度。
3. 底栏：上一步、下一步、分支或恢复操作，控制在约 64px。

页面本身 `overflow: hidden`。流程图以固定 1200×800 逻辑坐标绘制，通过 `viewBox` 和 `preserveAspectRatio` 自动等比缩放，始终完整放入左侧画布。

## 流程图视觉

- 模块底板最先绘制，连接线第二层绘制，节点最后绘制，避免连线被模块背景遮挡。
- 连接线从节点边缘到节点边缘，不穿过节点中心。
- 所有方向边都有箭头。
- 当前流转使用亮蓝线、移动光点和方向箭头。
- 已完成路径使用绿色；等待路径使用低亮灰蓝；跳过路径降低透明度。
- 并行、汇合、回传、重试、重规划使用不同线型与短标签，不能只靠颜色区分。
- 当前模块或节点允许增强亮度，但不得把其他架构隐藏或缩到不可辨认。

## 文字与对比度

- SVG 中文主文字显式设置浅白色 `fill`，不依赖 HTML `color` 继承。
- 英文与辅助说明使用浅蓝灰。
- 状态和强调色只用于边框、图标与少量标签，不把大段正文染成高饱和蓝色。
- 深色背景上的正文对比度至少达到 WCAG AA 的可读水平。

## 交互

- “下一步”推进一个执行事件，“上一步”恢复前一事件快照。
- 决策事件在底栏显示选择按钮；未选择前禁止推进。
- 并行事件逐支路完成，并在图中分别显示运行、完成和等待。
- 回传、重试和重规划直接在全景图上沿对应连接线演示。
- 模块内部有小步骤时，在右侧说明栏显示该模块内部子步骤及当前子步骤，不在画布上再打开第二层导航。
- 异常场景只显示有效恢复操作；普通下一步在异常未解决时禁用。

## 响应式与验收

- 1366×768、1440×900、1920×1080，浏览器缩放 100% 时无页面滚动。
- 所有主要节点和连接关系完整可见。
- 右侧说明栏和底栏不覆盖流程节点或连线。
- 中文主文字不得出现黑色或接近背景色。
- 从用户任务推进到最终响应时，当前流向在每一步都可辨识。
- 单文件 `dist/index.html` 离线打开后保持完整交互，不请求外部资源。

## 测试范围

- 视觉结构测试：模块、边、节点的 SVG 绘制顺序。
- 样式测试：SVG 主文字具有显式浅色 `fill`；页面禁止滚动。
- 状态测试：前进、后退、决策、并行、回传、重试、重规划。
- 浏览器尺寸测试：1366×768、1440×900、1920×1080 均无溢出，主流程完整可见。
- 构建测试：单文件产物无外部脚本、样式、字体或网络请求。
